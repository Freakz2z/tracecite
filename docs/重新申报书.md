# TraceCite 项目申报书

1. **项目名称**：TraceCite——AI Agent 独立证据验证与来源变化检测工具。
2. **项目简介**：使用 MoonBit 开发。工具会重新读取 HTTP/HTTPS 网页或本地文件，检查 Agent 引用的原文是否真实出现在当前来源中，并比较多次运行使用的来源是否发生变化；可用于 RAG、网页研究和 Agent 发布检查。
3. **项目方向与通用性**：Agent 开发与可信输出工具。提供无需适配器的 `claim + quote + URL` 输入，也提供公开 JSONL 事件格式和 Codex CLI 适配器，可接入不同 Agent、模型和检索系统。
4. **预期使用场景**：
   - RAG 团队将回答中的 claim、原文片段和网页 URL 写入笔记，发布前运行回源校验；若原文已被删除或回答引用错误，CI 阻止该版本进入发布流程。
   - 网页研究 Agent 输出带引用的竞品或政策摘要；审核者运行 TraceCite 重新请求每个公开网页，快速找出链接失效或引用不在当前页面的条目，再人工判断主张含义。
   - 知识库维护者在更新前后运行同一 Agent；TraceCite 按稳定来源 URI 比较两次内容，指出新增、删除或改动的来源，帮助定位需要重审的回答。
5. **拟实现的核心功能**：轻量引用笔记解析；HTTP/HTTPS 回源和 HTML 可见文本提取；逐字引用核对；本地文件回读；Agent 调用与引用关联校验；多次运行来源差异比较；稳定错误码、JSON 报告和 CI 命令行。
6. **项目性质**：原创项目，非移植项目。核心数据约定、回源工作流和验证逻辑由本项目设计实现。
7. **移植项目来源与许可证**：不适用。项目使用 Apache-2.0 许可证，并依赖同为 Apache-2.0 的 MoonBit HTML 解析库。
8. **GitHub 仓库**：[https://github.com/Freakz2z/tracecite](https://github.com/Freakz2z/tracecite)（公开仓库已有不少于 10 个有效功能开发提交）。

**验证边界**：通过表示引用片段在检查时出现在独立读取的来源里，不等于证明 claim 在语义上正确；网页会变化，跨运行比较依赖稳定来源 URL。
